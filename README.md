**NumPy and Pandas Data Analysis Project**

**Project Overview**

This project focuses on performing data analysis using Python libraries such as NumPy and Pandas. The main objective is to understand numerical computations, data manipulation, indexing, slicing, filtering, and aggregation techniques.

The assignment uses temperature data, student marks, and transaction records to demonstrate real-world data analysis operations.

**Objectives**

Work with NumPy arrays for numerical computations.

Create and manipulate one-dimensional and two-dimensional arrays.

Perform array indexing, slicing, and mathematical operations.

Create and manipulate Pandas Series.

Understand Pandas DataFrames and their properties.

Apply filtering, grouping, aggregation, and data manipulation techniques.

**Project Tasks**

**1. NumPy Array Operations**

Create a one-dimensional temperature array for Week 1.

Inspect array shape, data type, and number of elements.

Convert Celsius temperatures into Fahrenheit.

Calculate maximum, minimum, and mean temperatures.

Perform array indexing and slicing.

Create a two-dimensional array containing two weeks of temperatures.

Extract weekly and weekend temperatures.

**2. Pandas Series**

Create a Series named marks with custom index labels.

Access values using integer indexing, loc, and iloc.

Apply Boolean filtering to identify marks greater than 90.

Modify the first-ranked student's marks.

Remove the last-ranked student's entry.

Calculate CGPA by dividing marks by 10.

**3. Pandas DataFrame**

Create a DataFrame named transactions.

Display the first and last rows.

Inspect DataFrame shape, columns, and data types.

Select specific columns using indexing.

Filter transactions based on region and amount.

Calculate category value counts.

Identify unique regions.

Group transactions by region and calculate average amounts.

Modify transaction amounts.

Add and remove a Discount column.

Delete a specific transaction record.
